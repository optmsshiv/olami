HOW TO UPLOAD (cPanel / Hosting):
1. Upload ALL files inside this folder to public_html/ (not the folder itself)
2. Keep the structure exactly as-is:
   /index.html, about.html, services.html, portfolio.html,
   process.html, pricing.html, blog.html, contact.html,
   coming-soon.html, favicon.png, favicon.ico, .htaccess
   /assets/css/style.css
   /assets/js/main.js
   /assets/images/ (logo + transparent logo + favicon + Ola photo)
3. SSL: Make sure SSL / HTTPS is ON in hosting, then your site shows Secure.
4. Coming Soon: To launch in 2 days, rename coming-soon.html to index.html
   temporarily, OR set your host to show coming-soon.html first.
   For final launch, keep index.html as homepage.
